===============================================================================
TECHNICAL CHALLENGES SOLVED
===============================================================================

1. JWT Key Mismatch
   - Problem: Frontend and backend used different JWT keys
   - Solution: Unified to single key in appsettings

2. .NET Version Upgrade
   - Problem: Started with .NET 8.0, needed .NET 9.0
   - Solution: Upgraded all projects and NuGet packages

3. Database Refactoring
   - Problem: Single users table not scalable
   - Solution: Split into admins, dealers, customers tables

4. Cart Not Loading Items
   - Problem: GetAllAsync() didn't include items
   - Solution: Used GetQueryable().Include(Items).FirstOrDefault()

5. Order Service Timeout
   - Problem: Deep .Include() chains caused query explosion
   - Solution: Batch-loading with FindAsync() and ToDictionary()

6. Cart Add-to-Cart Bug
   - Problem: ProductCard called PUT instead of POST
   - Solution: Fixed to use addToCart() for new items

7. Supabase Connection
   - Problem: Cloud database with SSL and connection limits
   - Solution: Configured pooling=false, increased timeouts

8. Dealer URL Mismatch
   - Problem: Frontend used /dealers (plural) but backend used /dealer (singular)
   - Solution: Changed backend route to api/dealers to match frontend
